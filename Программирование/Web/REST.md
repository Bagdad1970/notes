
REST API (Representational State Transfer API) - архитектурный стиль взаимодействия между клиентом и сервером через HTTP (в основном). Он определяет принципы построения API, обеспечивая стандартизированный и эффективным обмен данными медлу различными системами.

Принципы:
- Клиент-серверная архитекутура
- Отсутствие состояния (stateless). Каждый запрос от клиента к серверу обрабатывается независимо от предыдущих запросов.
- Кэширование
- Единообразозие интерфейса. Все ресурсы REST API должны иметь четкую структуру и единообразие URL-адреса. Запросы выполняется выполняются с использованием стандартных методов HTTP, а данные передаются в JSON или XML.
- Система уровней (Layered System). REST API может включать балансировщики нагрузки, прокси-серверы и т.д.
