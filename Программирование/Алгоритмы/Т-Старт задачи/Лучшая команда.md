## Решение

```python
numbers = [  
    input()  
]  
  
n = int(numbers[0])  
  
team_dict = {}  
for i in range(n):  
    team = sorted(input().split())  
    joined_team = ' '.join(team)  
  
    if joined_team not in team_dict:  
        team_dict[joined_team] = 1  
    else:  
        team_dict[joined_team] += 1  
  
print(max(team_dict.values()))
```
