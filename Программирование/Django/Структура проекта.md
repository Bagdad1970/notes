При непосредственно создании Django проекта его структура будет иметь следующий вид:
```
my_project/  
├── manage.py  
├── my_project/  
│   ├── __init__.py  
│   ├── asgi.py  
│   ├─ settings.py  
│   ├─ urls.py  
│   ├── wsgi.py  
├── my_app/  
    ├── migrations/  
    │   └── __init__.py  
    ├── __init__.py  
    ├── admin.py  
    ├── apps.py  
    ├── models.py  
    ├── tests.py  
    ├── urls.py  
    └── views.py
```

- `manage.py` - manage.py: этот небольшой, но мощный скрипт служит отправной точкой для различных команд управления Django. С его помощью вы запускаете сервер разработки, создаете приложения, выполняете миграцию и многое другое. manage.py — это дирижерская палочка, управляющая работой вашего проекта.

- `settings.py` - содержит настройки, которые определяют конфигурацию проекта Django. Здесь конфигурируется все — от конфигурации базы данных до списков middleware.

- `urls.py` - сопоставляет URL-адреса с templates. Этот файл определяет, какое представление будет отображаться при переходе по определенному URL-адресу.

- `asgi.py`

- `wsgi.py`

- `models.py` - определяет модели данных с помощью Django ORM.

- `views.py` - содержит логику, определяющую взаимодействие приложения с запросами пользователей. Представления отвечают за обработку данных, рендеринг шаблонов и реагирует на действия пользователя.

- `tests.py` - содержит модульные тесты приложения

- `admin.py` - предназначен не только для администраторов — он настраивает представление моделей вашего приложения в интерфейсе администратора Django.  Этот файл позволяет администраторам легко управлять данными.

- `migrations/` - хранит в директории все миграции моделей.
