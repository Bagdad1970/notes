Модель — это единый достоверный источник информации о данных. Она содержит основные поля и характеристики хранимых данных. Обычно каждая модель соответствует одной таблице в БД.

==class Meta==

Каждая модель представляет собой класс Python, являющийся подклассом `django.db.models.Model`.

Каждый атрибут модели представляет собой поле в базе данных.

Django автоматически генерирует API для взаимодействия с БД.

По умолчанию Django присваивает каждой модели первичный ключ с автоинкрементом, тип которого указывается для каждого приложения в `AppConfig.default_auto_field` или глобально в `DEFAULT_AUTO_FIELD`. 
Для добавления первичного ключа в модель явно, нужно указать `primary_key=True` для одного из полей. Тогда Django сам не будет добавлять первичный ключ.

`id = models.BigAutoField(primary_key=True)`

Каждая модель должна иметь ровно одно поле с `primary_key=True` явно или не явно.
