Приложения React создаются из изолированных частей пользовательского интерфейса, называемых **компонентами**.
**Компонент** - функция JavaScript, которую можно дополнить разметкой.

```typescript
export function SomeButton() {
	return (
		<button className="some-btn">
			Кнопка
		</button>
	);
}
```
