## Список (list)
Список - **упорядоченная** **изменяемая** коллекция объектов произвольных типов. В основе списка лежит массив, в котором все элементы имеют одинаковый размер и являются ссылками на реальные объекты.

Количество элементов хранится отдельно, чтобы `len()` не считала каждый раз фактическое количество элементов списка.

Способы создания списка:
1. `[elem_1, elem_2, ..., elem_n ]`
2. `list(iterable)`
3. List-comprehensions. `[expression(item) for item in iterable]`

Если массив уже заполнен и добавляется еще элемент, то выделяется новый и больший участок памяти под новый массив. После выделения все элементы копируются в новый массива. Аналогично, если из списка удаляется больше половины элементов, то список копируется в меньший участок памяти.

Основные методы:
- `append(x)` – добавляет элемент `x` в конец списка
- `extend(iterable)` – добавляет в конец списка все элементы из переданной итерируемой коллекции
- `insert(i, x)` – вставляет элемент x на позицию i
- `remove(x)` – удаляет первый элемент, равный x (вызывает ValueError, если элемент не найден)
- `pop([i])` – удаляет и возвращает элемент на позиции i (по умолчанию последний)
- `index(x[, start[, end]])` – возвращает индекс первого элемента, равного x
- `count(x)` – возвращает количество элементов, равных x
- `sort(*, key=None, reverse=False)` – сортирует список на месте
- `reverse()` – переворачивает список на месте

## Кортеж (tuple)
Кортеж - **упорядоченная** **неизменяемая** коллекция объектов произвольных типов.

Кортеж требует меньше памяти для использования, поскольку кортежу не нужно хранить дополнительные ячейки массива для новых элементов.

Способы создания кортежа:
1. `(elem_1, elem_2, ..., elem_n)`
2. `tuple(iterable)`

Основные методы:
- `count(x)` – возвращает количество элементов, равных x
- `index(x[, start[, end]])` – возвращает индекс первого элемента, равного x

## Множество (set)
Множество представляет неупорядоченную коллекцию уникальных элементов. Для добавления элемента в множество, он должен быть [[Хэширование|хэшируемым]].

Способы создания множества:
1. `{elem_1, elem_2, ..., elem_n}`
2. `set(iterable)`
3. Set-comprehension. `{expression for item in iterable}`

Основные методы:
- `add(x)` – добавляет элемент x в множество.
- `remove(x)` – удаляет элемент x. Если элемент не найден, будет выброшена KeyError.
- `discard(x)` – удаляет элемент x, если он присутствует (не вызывает ошибку)
- `pop()` – удаляет и возвращает произвольный элемент. Если множество пусто, то вызывает KeyError.

## Словарь (dict)
Словарь представляет ассоциативный массив. Для добавления элемента в словарь, он должен быть [[Хэширование|хэшируемым]].

Способы создания словаря:
1. `{key_1: value_1, key_2: value_2, ..., key_n: value_n}`
2. `dict(iterable)`
3. `.fromkeys(iterable, value=None)`. Создает словарь на основе итерируемого объекта с ключами (iterable) и значением по умолчанию (value).

Основные методы:
- `keys()` – возвращает список-представление всех ключей `dict_keys` словаря. `dict_keys` является динамичным объектом т.е. все изменения, такие как удаление или добавление ключей в словаре сразу отражаются на этом представлении
- `values()` – возвращает список-представление всех значений `dict_values` словаря. `dict_values` является динамичным объектом т.е. все изменения, такие как изменение или добавление значений в словаре сразу отражаются на этом представлении
- `items()` – возвращает новый список-представление `dict_items` пар элементов словаря `dict`, такой как `(key, value)`. `dict_items` является динамичным объектом т.е. все изменения в словаре сразу отражаются на этом представлении
- `get(key[, default])` – возвращает значение по ключу, если ключ отсутствует – возвращает default (по умолчанию None)
- `pop(key[, default])` – удаляет и возвращает значение по ключу; если ключ отсутствует и задан default – возвращает его, иначе `KeyError`
- `popitem()` – удаляет и возвращает последнюю добавленную пару (ключ, значение)
- `update([other])` – обновляет словарь, добавляя пары из другого словаря или итерируемого объекта
- `setdefault(key[, default])` – возвращает значение по ключу; если ключа нет, вставляет ключ со значением default и возвращает default
