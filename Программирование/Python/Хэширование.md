Функция `hash()` возвращает хеш-значение объекта, если оно есть. Хэш-значения являются целыми числами. Они используются для быстрого сравнения ключей словаря во время поиска в словаре. Для возможности хэширования объекта, он должен реализовать метод `__hash__()`.

Числовые значения, которые при сравнении дают одинаковый результат, имеют одинаковый хэш, даже если они относятся к разным типам (например, 1 и 1.0).

Реализация метода `__hash__()` должна гарантировать выполнение следующего условия: `IF a == b THEN hash(a) == hash(b)`, но `IF hash(a) == hash(b) MAY a != b`.

Хэш может быть вычислен только для неизменяемых типов (int, str, tuple, frozenset, ...), но для изменяемых (list, dict, set, ...) по умолчанию `hash = None`.

Хэш не работает с изменяемыми объектами, потому что при изменении объекта, уже хранящегося во множестве или словаре, его хэш пересчитывается и его нельзя больше найти.
