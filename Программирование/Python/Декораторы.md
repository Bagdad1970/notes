Декораторы функций - это простой способ модификации поведения любой функции без внесения изменения в ее код. Они часто лежат в основе многих библиотек.

Декораторы позволяют выполнить произвольный код до/после/вместо вызова функции, модифицируя ее входные аргументы, результат выполнения и добавляя различные побочные эффекты.

Грубо говоря: Декоратор - это функция, принимающая на вход функцию, и возвращающая другую функцию

Простейший декоратор:
```python
def decorator(
	call  # принимает на вход функцию
):
	def wrapper(*args, **kwargs):
		# код до оригинальной функции
		r = call(*args, **kwargs)
		# код после оригинальной функции
		return r
	return wrapper # возвращает другую функцию

def call(a: int) -> str:
	"""Returns string representation of an integer"""
	return str(a)
	
decorated_call = decorator(call)  # переменная decorated_call есть function

>>> decorated_call(1)
'1'
```

Для удобства можно использовать синтаксический сахар:
```python
@null_decorator
def greet():
	return 'Hello!'
	
>>> greet()
'Hello!'
```

#### Проблемы с метаинформацией
Оригинальная функция `call` заменяется функцией `wrapper`, и вы больше не можете получить доступ к `call` в глобальной видимости. Это черевато тем, что будет потеряна вся метаинформации оригинальной функции - название функции, докстринги, список входящих аргументов, их типы и т.д.

```python
>>> call.__name__
'call'
>>> decorated_call.__name__
'wrapper'

>>> call.__doc__
'Returns string representation of an integer'
>>> decorated_call.__doc__
  # ничего нет
  
>>> inspect.getfullargspec(call).args  # получаем аргументы функции
['a']
>>> inspect.getfullargspec(decorated_call).args
[]
```

Для решения этой проблемы используется функция `functols.wraps(func)`. Она копирует всю служебную метаинформацию о декорируемой функции в функцию-декоратор.
```python
from functools import wraps

def decorator(
	call
):
	@wraps(call)
	def wrapper(*args, **kwargs):
		r = call(*args, **kwargs)
		return r
	return wrapper
```

Это нужно как минимум для того, чтобы библиотеки, получающие информацию о ваших функциях через модуль `inspect` работали корректно (тот же FastAPI не сможет распознать аргументы вашей функции без этого).
