## Итераторы
Итерируемый объект (iterable) - это объект, который способен возвращать элементы по одному. Для Python это любой объект, который реализует метод `__iter__()` или `__getitem__()`.  Такой объект можно использовать в `for`, `map`, `filter`, `sorted`, `enumerate` и других.

Итератор (Iterator) - объект, который возвращает свои элементы по одному за раз и реализует протокол итератора. Протокол итератора содержит следующие методы:
1. `__iter__()` - возвращает сам объект итератора. Необходим для использования операторов `for` и `in` с контейнерами и итераторами.
2. `__next__()` - возвращает следующий элемент из итератора. Если элементов больше нет, генерирует исключение `StopIteration`.

Функция `iter(iterable, /)` - возвращает итератор. `iterable` должен реализовывать метод `__next__()` или `__getitem__()`.

Функция `next(iterator, default=None, /)` - получает следующий элемент итератора путем вызова метода `__next__()`. Если указан `default`, то он будет возвращен в случае исчерпания итератора.

## Генератор
**Генератор** - это особый вид итератора. Генераторной функцией называется любая функция, содержащая `yield`. При вызове генераторная функция возвращает генератор.
```python
# генераторная функция
def gen_function():
	yield 10

# gen есть генератор
gen = gen_function(5)
```

Так же как и итератор, генератор не хранит все значения, а вычисляет их "на лету". Генератор можно обойти только один раз.
Схема выполнения генераторной функции:
1. При запросе значения из генератора выполняется тело генератора до `yield`.
2. Встретив `yield` генератор запоминает позицию выполнения кода и возвращает значение, стоящее справа от `yield`. Если значение справа от `yield` отсутствует, то генератор возвращает `None`.
3. При следующем запросе выполнение продолжится с сохраненной позиции до следующего `yield` и так же вернется значение справа от `yield`.

Пример:
```python
def gen_function(n):
    while n > 0:  # (1)
        yield n  # (2)
        n -= 1

gen = gen_function(5)  # (3)

print(next(gen))  # (4)

# вызов __next__() у генератора
print(gen.__next__())

print(next(gen))
print(next(gen))
print(next(gen))
```

(1) - стартовая позиция генератора при его создании в (3).
(2) - встретив `yield` генератор возвращает значение в переменной `n` и запоминает свою позицию.
(4) - при вызове метода `next` генератор выполняется до тех пор, пока не встретит `yield`

Применение генераторов:
- **Чтение больших файлов построчно.** Если файл очень большой, загружать его целиком в память неэффективно. Генератор позволяет читать файл построчно.
- **Реализация ленивых вычислений**
- **Анализ почти бесконечного потока данных**. Например, необходимо в реальном времени обрабатывать показания счетчиков, сетевой трафик и т.д.
