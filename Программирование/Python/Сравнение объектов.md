Существует два разных способа сравнения объектов:
1. сравнение **идентичности** (identity)
2. сравнение **равенства** (equality)

### Сравнение идентичности
Идентичность означает, что два имени ссылаются на один и тот же объект в памяти. 

Оператор `is` сравнивает идентификаторы объектов, возвращаемые функцией `id()`.
Также полезен для:
- сравнения с уникальными объектами `None`, `True` и `False`
- проверки типов

**Замечание**: не следует использовать `is` для сравнения чисел, поскольку `x is y` может давать разный результат в зависимости от величины самих чисел `x` и `y`.

##### Функция id
Встроенная функция `id()` возвращает уникальное целое число (идентификатор), которое остается неизменным для объекта на протяжении всего времени его жизни. В большинстве реализаций Python это число представляет собой фактический адрес объекта в оперативной памяти.

### Сравнение равенства
Равенство же означает, что содержимое или значение объектов одинаково, даже если это физически разные объекты в памяти.

Пусть необходимо сравнить два объекта на равенство `a == b`. Тогда будет вызван метод `a.__eq__(b)`. Если метод `__eq__()` не реализован в классе `a`, тогда будет вызван метод `b.__eq__(a)`. Если метод `__eq__()` не реализован и в классе `b`, то результатом сравнения будет False.

Примеры сравнений:
```python
a = [1, 2]
b = [1, 2]
a == b  # True
a is b  # False
```
