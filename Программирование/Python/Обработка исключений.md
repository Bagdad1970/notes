
Исключение Python представляет собой объект, описывающий исключительное (ошибочное) состояние, которое произошло внутри фрагмента кода. Когда возникает исключение, PVM генерирует объект-исключение, который затем передается по стеку вызовов, пока не будет найден блок кода, способный его обработать.

### Иерархия исключений

![[Pasted image 20260730204525.png|646]]

Только объекты класса BaseException и его наследники могут генерироваться PVM и использоваться в операторах raise и except.

Объект исключения содержит:
- Стек вызовов (traceback) - информацию о последовательности вызовов функций на момент возникновения исключения
- Строку сообщения об ошибке (через аргументы конструктора)
- Дополнительные атрибуты (для пользовательских исключений)

### Синтаксис исключений
Для обработки исключений используется следующий синтаксис:
```python
try:
	// исполняемый код, где могут быть ошибки
except тип_исключения1 :
	// обработка данного исключения
except (тип_исключения2, тип_исключения3) [as объект_искл]:
	// одинаковая обработка перечисленных типов исключений
...  // дополнительные except, если нужно
else:
	// код, который выполняется, если в блоке try не произошло ошибок
finally:
	// код, который должен быть выполнен в любом случае
```

Для генерации исключения в коде используется оператор `raise`.
Пример:
```python
if a >= 100:
	raise Exception("The variable a must be less than 100")
```

### Пользовательские исключения
Класс пользовательского исключения должен быть унаследован от класса `Exception` или его наследника.

```python
class CustomException(Exception):
	"Custom exception"
```
