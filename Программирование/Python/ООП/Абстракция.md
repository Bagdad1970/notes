Абстракция означает выделение общих свойств и методов объектов, и опускание деталей реализации.

### @abstractmethod
Декоратор, определяющий абстрактный методы. Если подкласс не реализует абстрактный метод, объект не создастся и будет выброшена ошибка `TypeError`.

Создать объект абстрактного класс (унаследованного от `abc.ABC`) нельзя - будет выброшена `TypeError`.

Абстрактные методы могут быть вызваны с использованием любого из обычных механизмов вызова "super".

Если `@abstractmethod` применяется в сочетании с другими декораторами методов (`@staticmethod`, `@classmethod`, `@property`, ...), то `@abstractmethod` должен быть внутренним декоратор

```python
class C(ABC):
    @abstractmethod
    def my_abstract_method(self, arg1):
        pass
        
    @classmethod
    @abstractmethod
    def my_abstract_classmethod(cls, arg2):
        pass
        
    @staticmethod
    @abstractmethod
    def my_abstract_staticmethod(arg3):
        pass

    @property
    @abstractmethod
    def my_abstract_property(self):
        pass
        
    @my_abstract_property.setter
    @abstractmethod
    def my_abstract_property(self, val):
        pass
```

Пример:
```python
from abc import ABC, abstractmethod  

class Shape(ABC):
    def __init__(self, x, y):
        self.x = x
        self.y = y 
         
    @abstractmethod     
    def area(self):
	    pass
     
    def print_point(self):
        print("X:", self.x)
        print("Y:", self.y)

class Rectangle(Shape):
    def __init__(self, x, y, width, height):
        super().__init__(x, y)
        self.width = width
        self.height = height
        
    def area(self):
	    return self.width * self.height
```
