## self
Переменная `self` используется для представления экземпляра класса, . Она работает как ссылка на объект. `self` в качестве параметра используется для обращения к его атрибутам и методам.

```python
class Rectangle:  
    def __init__(self,x = 0,y = 0):  
        self.x = x  
        self.y = y  
  
    def area (self):  
        return self.x * self.y
```

```python
rec = Rectangle(6, 10)

>>> rec.area()
60

>>> Rectangle.area(rec)
60

>>> type(Rectangle.area)
<class 'function'>

>>> type(rec.area)
<class 'method'>
```

Особенность Python заключается в том, что сам объект передается в качестве первого аргумента соответствующей функции. В приведенном примере вызов метода `rec.area()` эквивалентен `Rectangle.area(rec1)`. 

Как правило, при вызове метода с некоторыми аргументами вызывается соответствующая функция класса, помещая объект метода перед первым аргументом. 
Поэтому `obj.method(args)` становится `Class.method(obj, args)`. Поэтому первым параметром функции в классе должен быть сам объект.


## cls
Переменная `cls` используется для представления класса. Она работает как ссылка на сам класс. `cls` в качестве параметра используется для обращения к атрибутам и методам класса.

```python
class Rectangle:  
    default_color = "black"  # атрибут класса  
  
    def __init__(self, x=0, y=0):  
        self.x = x  
        self.y = y  
  
    @classmethod  
    def get_default_color(cls):  
        return cls.default_color  
  
    @classmethod  
    def create_square(cls, size):  
        return cls(size, size)  # (1)
```

(1) - здесь используется `cls`, а не имя класса, потому что при наследовании будет подставлен тот класс, через который был вызван метод.

**Замечание**: `self` и `cls` не являются ключевыми словами, поэтому можно использовать любое название для представления экземпляра. Однако, принято использовать `self` и `cls` соответственно
