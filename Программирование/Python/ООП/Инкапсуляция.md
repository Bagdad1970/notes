Объединение свойств и методов внутри единой оболочки (например, класса), а также ограничение прямого доступа к ним извне. Защищает данные от некорректного использования и позволяет скрывать детали реализации, предоставляя лишь необходимый публичный интерфейс.

### Модификаторы доступа
Модификаторы доступа управляют видимостью классов, методов и полей, тем самым определяя, как к компонентам класса можно получить доступ из других частей программы.

В отличие от других языков в Python модификаторы являются по большей частью формальностью. Они поддерживаются только соглашениями о наименовании и name mangling. К любому полю и методу можно получить доступ извне.

##### name mangling
В Python name mangling - механизм, который защищает методы класса и его атрибуты от случайного переопределения или доступа к ним извне класса.

При добавлении к названию поля или методу `__` Python изменяет название, добавляя символ подчеркивания и название класса в начало имени.
Пример: в классе `Klass` поле  `__field` станет `_Klass__field`.

В Python используются следующие модификаторы доступа:
1. **public**. `field`
2. **protected**. `_field_`
3. **private**. `__field__`

Пример с инкапсуляцией:

```python
class SomeClass:  
    def __init__(self,
	    public_field = "public_field",
		protected_field = "protected_field",
		private_field = "private_field"
	):  
        self.public_field = public_field  
        self._protected_field = protected_field  
        self.__private_field = private_field
        
    def __private_method(self):  
	    return "private_method"
        
>>> obj = SomeClass()
>>> obj.__dict__  # получаем все поля объекта
{'public_field': 'public_field', '_protected_field': 'protected_field', '_SomeClass__private_field': 'private_field'}

>>> obj.__private_field
Traceback (most recent call last):
  File "<input>", line 1, in <module>
AttributeError: 'SomeClass' object has no attribute '__private_field'

>>> obj._SomeClass__private_field
'private_field'

>>> obj._SomeClass__private_method()
'"'private_method'
```
