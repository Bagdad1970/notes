### Конструирование и инициализация

1. `__new__(cls, [...])`. Первый метод, вызываемый при создании экземпляра. Получает класс и аргументы конструктора. Используется редко, например, при наследовании от неизменяемых типов (str, tuple).
    
2. `__init__(self, [...])`. Конструктор класса. Вызывается после `__new__`. Ему передаются все аргументы, переданные конструктору (`SomeClass(arg1, arg2)`). Самый распространенный метод для установки начального состояния объекта.
    
3. `__del__(self)`. Деструктор. Определяет поведение при удалении объекта сборщиком мусора. Полезен для закрытия внешних ресурсов (файлов, сокетов), но его вызов не гарантирован, поэтому не должен быть основной логикой очистки.
    

### Сравнение объектов

1. `__eq__(self, other)`. Определяет поведение оператора равенства (`==`).
    
2. `__ne__(self, other)`. Определяет поведение оператора неравенства (`!=`).
    
3. `__lt__(self, other)`. Определяет поведение оператора "меньше" (`<`).
    
4. `__gt__(self, other)`. Определяет поведение оператора "больше" (`>`).
    
5. `__le__(self, other)`. Определяет поведение оператора "меньше или равно" (`<=`).
    
6. `__ge__(self, other)`. Определяет поведение оператора "больше или равно" (`>=`).

### Строковое представление

1. `__str__(self)`. Определяет поведение функции `str()`, вызыванной для экземпляра. Предназначен для удобочитаемого вывода.
    
2. `__repr__(self)`. Определяет поведение функции `repr()`. Ориентирован на машинно-читаемый вывод (часто это должен быть валидный код на Python).
3. `__copy__(self)`. Определяет поведение `copy.copy()` (поверхностное копирование).
    
4. `__deepcopy__(self, memodict={})`. Определяет поведение `copy.deepcopy()` (глубокое копирование).

6. `__hash__(self)`. Определяет поведение функции `hash()`. Должен возвращать целое число. При определении `__eq__` обычно нужно переопределять и `__hash__`.

### Управление доступом к атрибутам

1. `__getattr__(self, name)`. Вызывается, когда пользователь пытается обратиться к несуществующему атрибуту. Полезно для перехвата обращений или динамического создания атрибутов.
    
2. `__setattr__(self, name, value)`. Вызывается при любой попытке присвоить значение атрибуту. Требует осторожности, чтобы избежать бесконечной рекурсии (используйте `self.__dict__[name] = value` или `super().__setattr__(name, value)`).
    
3. `__delattr__(self, name)`. Вызывается при попытке удалить атрибут (`del self.name`). Требует тех же мер предосторожности, что и `__setattr__`.
    
4. `__getattribute__(self, name)`. Вызывается при любом обращении к атрибуту (включая существующие). Использовать с осторожностью из-за высокой сложности и риска рекурсии.
    

### Контейнеры и последовательности

1. `__len__(self)`. Возвращает количество элементов. Используется функцией `len()`.
    
2. `__getitem__(self, key)`. Определяет доступ к элементу через синтаксис `self[key]`. Должен выбрасывать `KeyError` или `TypeError`.
    
3. `__setitem__(self, key, value)`. Определяет присваивание элементу через `self[key] = value`. Для изменяемых контейнеров.
    
4. `__delitem__(self, key)`. Определяет удаление элемента через `del self[key]`.
    
5. `__iter__(self)`. Возвращает итератор для контейнера. Вызывается функцией `iter()` и в циклах `for`.
    
6. `__contains__(self, item)`. Определяет поведение для операторов `in` и `not in`. Если не определен, Python перебирает контейнер последовательно.

### Вызова объекта как функции

1. `__call__(self, [args...])`. Позволяет экземпляру класса быть вызванным как функция (`x()` эквивалентно `x.__call__()`). Полезно для объектов, изменяющих состояние.

### Числовые операции

1. `__add__(self, other)`. Сложение (`+`).
2. `__sub__(self, other)`. Вычитание (`-`).
3. `__mul__(self, other)`. Умножение (`*`).
