Функция `super()` обеспечивает доступ к оригиналам наследованных методов. Возвращает прокси объект, делегирующий вызовы методов родителю или брату класса (в случае ромбовидного наследования).

Синтаксис:
`super(type, object-or-type)`,
где
`type` - (необязательный) тип, от которого начинается поиск объекта-посредника
`object-or-type` - (необязательный) тип или объект, определяет порядок разрешения метода для поиска

Используется для:
1. **Доступа к переопределённым методам родителя**. Позволяет вызвать родительскую версию родителя.
2. **Расширения функциональности родительского метода**. Вместо полной замены вы добавляете свою логику **в дополнение** к родительской.
3. **Корректной работы с множественным наследованием** (MRO — Method Resolution Order)  `super()` следует порядку разрешения методов, что предотвращает проблемы с "ромбовидным" наследованием.
4. **Упрощения поддержки кода**. Если изменится имя родительского класса, не нужно править вызовы по всему коду.

#### Использование в конструкторах
Если в конструкторе дочернего класса не вызывать super(), то родительские поля будут непроинициализированы.

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)  # динамически вызывает родительский __init__
        self.breed = breed
```
