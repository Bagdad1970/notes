Модуль enum

представляет собой набор символьных имен (элементов), привязанных к уникальным значениям. 

можно проитерироваться 

может быть обработан для возврата канонических (т.е. не псевдонимных) элементов в порядке определения

использует `call` для возврата элементов по значению

возможно обращение по индексу для возврата элемента перечисления по имени
