Пространство имен - это контейнер, который хранит коллекцию идентификаторов, таких как перменные, имена функций, а также соответсвующие им объекты. Представляет собой словарь , в котором имена сопоставляются с объектами. Причем каждое имя является уникальным в своей области видимости.

Всего существует 4 пространства имен:
1. Built-in
2. Global
3. Local
4. Enclosing (nonlocal)

При выполнении программы Python создает пространства имен по мере необходимости и удаляет их, когда они больше не нужны. Глобальные, локальные и нелокальные пространства имен Python реализованы в виде словарей. В отличие от них, пространство имен built-in не является словарем, а представляет собой модуль, называемый builtins. Этот модуль выступает в качестве контейнера для пространства имен built-in.

### Built-in
Built-in пространство содержит имена всех встроенных объектов Python. Оно доступно во время работы интерпретатора Python. Built-in пространство создается при запуске интерпретатора и удаляется только при завершении работы интерпретатора.

### Global
Global пространство имен содержит имена, определенные на уровне модуля. При запуске основной части  программы создается основное Global пространство имен, которое существует до завершения работы интерпретатора. Кроме того, каждый модуль имеет свое Global пространство имен. Интерпретатор создает глобальное пространство имен для любого модуля, который программа загружает с помощью оператора `import`.

### Local
При вызове функции создается Local пространство имен, которое ссуществует только до тех пор, пока функция не вернет управление.

### Enclosing (nonlocal)
Enclosing (nonlocal) - это область, которая возникает только при наличии вложенных функций. По сути, представляет Local пространство имен внешней функции, которая содержит вложенные функции.

Доступ и модификация: Вложенные функции могут читать переменные из окружающего пространства имен, но для изменения или повторной привязки необходимо использовать ключевое слово `nonlocal`.

Это пространство имен существует до тех пор, пока выполняется внешняя функция. Если внутренняя функция возвращается в виде замыкания, окружающее пространство имен запоминается даже после завершения внешней функции.

==Практика - пример==


Пример пространств имен:
```python
global_var = "global"  # global

def outer():
    outer_var = "enclosing"  # enclosing
    
    def inner():
        inner_var = "local"  # local

        print(len([1,2,3]))   # len and print from built-in
    
    inner()

outer()
```

## global и nonlocal
Во время выполнения может понадобиться изменять значения глобальных и nonlocal переменных.

global

```python
x = 20
def f():
    global x
    x = 40
    print(x)
```

Оператор `global x` указывает, что во время выполнения функции `f()` ссылки на переменную `x` будут ссылаться на глобальную переменную `x`. Это означает, что `x = 40` не создает новую локальную переменную, а изменит глобальную.

## Области видимости
Наличие нескольких отдельных пространств имен позволяет одновременно использовать несколько разных экземпляров одного и того же имени во время выполнения программы. Каждый экземпляр является независимым и не мешает другим. Это достигается определением отдельных областей видимости. Область видимости — это область программы, в которой пространство имен доступно напрямую. Интерпретатор определяет это во время выполнения на основе того, где встречается определение имени и где на это имя ссылаются в коде.

Пусть необходимо найти некоторую переменную. Тогда процесс поиска переменной будет происходить в следующем порядке:
`Local -> Enclosing -> Global -> Built-in`
Если даже в Built-in не будет найдена переменная, то будет выброшено исключение `NameError`.
