**Spring Boot Starter** - это предварительно упакованные наборы зависимостей и сконфигурированных бинов для обеспечения определенной функциональности.

Примеры:
- `spring-boot-starter-web` - для работы с Spring Web и MVC
- `spring-boot-starter-security` - для организации защищённого доступа к ресурсам сервиса
- `spring-boot-starter-test` - для написания тестов с подъёмом Spring контейнера
