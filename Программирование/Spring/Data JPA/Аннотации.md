
## @Table
Используется для определения сопоставления таблиц БД для объекта.
Позволяет настраивать:
- name: Задает имя таблицы БД (по умолчанию имя класса)
- catalog: Определяет имя каталога БД
- schema: Определяет схему таблицы
- uniqueConstraints: Устанавливает уникальные ограничения целостности для одного или нескольких столбцов

Пример:
```java
@Entity
@Table(
    name = "EMPLOYEE",
    uniqueConstraints = { @UniqueConstraint(columnNames = "email") }
)
public class Employee {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private int id;

    @Column(nullable = false, unique = true)
    private String email;
}
```

## @Id
Помечает поле как первичный ключ объекта. Уникально идентифицирует каждую строку в соответствующей таблице БД и является обязательным для каждого объекта.

```java
@Entity 
public class Employee { 
    @Id 
    @GeneratedValue(strategy = GenerationType.IDENTITY) 
    private Long id; 
    private String name;
}
```

## @Entity
Показывает, что класс является сущностью и может представлять таблицу в БД. JPA рассматривает такой класс его как постоянный объект Java, состояние которого может храниться в БД и извлекаться из нее.
Особенности:
- Класс должен иметь конструктор без аргументов.
- Поле первичного ключа должно быть помечено аннотацией `@Id`.

Пример:
```java
@Entity
public class Student {

    @Id
    private int id;
    private String name;
}
```

## @Enumerated
Указывает, что поле должно быть сохранено как enum. Эта аннотация необязательна, если тип поля является Java enum.
В аннотации можно указать во что необходимо преобразовать enum:
- в строку - `EnumType.String`
- в целое число - `EnumType.Ordinal`

Пример:
```java
@Entity
public class Article {
    @Id
    private int id;
    
    @Enumerated(EnumType.STRING)
    private Type type;
}
```
