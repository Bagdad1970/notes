Поток выполнения в JavaScript работает за счёт цикла событий (**event loop**), который отвечает за выполнение кода, сбора и обработки событий и задач из очереди.

Event Loop состоит из 2 основных компонентов: **стек вызовов (call stack)** и **очереди событий (event queue)**.

### Стек вызовов
Call stack определяет порядок выполнения кода и хранит локальные переменные. 
Вызов любой функции создаёт контекст выполнения ([Execution Context](https://developer.mozilla.org/en-US/docs/Web/API/HTML_DOM_API/Microtask_guide/In_depth#JavaScript_execution_contexts)). При вызове вложенной функции создаётся новый контекст, а старый сохраняется в call stack. Когда выполнение завершается, контекст извлекается из стека, и код продолжает выполнение с предыдущей функции.

Пример:
```javascript
const foo = (b: number) => {  
    const a = 12;  
    return a + b + 10;  
}  
  
const bar = (x: number) => {  
    const m = 4;  
    return foo(m * x);  
}

bar(21);
```

Когда вызывается функция `bar`, создаётся первый контекст выполнения, содержащий аргументы функции `bar` и локальные переменные. Когда `bar` вызывает `foo`, создаётся второй контекст с аргументами `foo` и её локальными переменными. И контекст выполнения `foo` помещается в стек вызовов выше первого. Когда `foo` возвращает результат, верхний элемент из стека удаляется. Когда `bar` возвращает результат, её контекст также удалится, и стек становится пустым.


### Очередь событий
Очередь событий представляет собою список задач, подлежащих обработке. Каждая задача ассоциируется с некоторой функцией, которая будет вызвана, чтобы обработать эту задачу.
Когда стек вызовов полностью освобождается, самая первая задача извлекается из очереди и обрабатывается. Обработка задачи состоит в вызове ассоциированной с ней функции с параметрами, записанными в этой задаче. Как обычно, вызов функции создаёт новый контекст выполнения и заносится в стек вызовов.
Обработка задачи заканчивается, когда стек снова становится пустым. Следующая задача извлекается из очереди и начинается её обработка.
Каждая задача выполняется полностью, прежде чем начнёт обрабатываться следующая т.е. исполняемая функция не может быть приостановлена.

Когда в коде встречается асинхронная операция, то она не блокирует выполнение остального кода, а помещается в event queue для дальнейшего выполнения.


В Javascript задачи делятся на **микрозадачи** и **макрозадачи**.
Макрозадачи выполняются после завершения микрозадач.
Примеры макрозадач: выполнени скрипта, обновление DOM, setTimeout(), setInterval().

Микрозадачи связаны с асинхронными операциями. Они выполняются после завершения текущего стека вызовов и перед следующим событием цикла событий.
Примеры микрозадач: `Promise.then/catch/finally`, `async/await`

**Замечание**: в рамках итерации цикла обработки сначала выполняются все микрозадачи, находящиеся в event queue, а затем выполняется макрозадача.
