
@NonNull

Использовуется для компонента записи или параметра метода или конструктора. Это приведет к тому, что lombok сгенерирует для вас инструкцию проверки нулевого значения.

Lombok всегда рассматривал различные аннотации, обычно называемые @NonNull в поле, как сигнал для генерации проверки на нулевое значение, если lombok генерирует для вас весь метод или конструктор, например, с помощью @Data. Однако, используя собственный @lombok от lombok.Значение, отличное от значения NULL для параметра или компонента записи, приводит к вставке нулевой проверки в начало этого метода.

Проверка null выглядит следующим образом:
```java
if (param == null) {
	throw new NullPointerException("param is marked non-null but is null")
} 
```

Куда вставляется проверка:
- **Метод** - в начало
- **Конструктор** - после любых явных вызовов `this()` или `super()`.
- **record** - компактный конструктор (без списка аргументов);

Если в начале уже присутствует нулевая проверка, дополнительная проверка сгенерирована не будет.
