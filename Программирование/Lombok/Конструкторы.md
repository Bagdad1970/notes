
Для создания конструкторов используется три аннотации:
- `@NoArgsConstructor`
- `@RequiredArgsConstructor`
- `@AllArgsConstructor`

## @NoArgsConstructor
Сгенерирует конструктор без параметров.
Если это невозможно из-за использвования final полей, то возникнет ошибка компилятора. Для избежания ошибки можно указать параметр `force = true`, тогда все final поля инициализируются значением по умолчанию (0, false, null и т.д.).
Для полей с ограничениями (например с `@NonNull`) проверка не выполняется, поэтому имейте в виду, что эти ограничения, как правило, не будут выполнены до тех пор, пока эти поля не будут должным образом инициализированы позже.

## @RequiredArgsConstructor
Сенерирует конструктор с 1 параметром для каждого поля, требующего специальной обработки. К таким полям относятся final и отмеченные @NonNull. Для полей, помеченных @NonNull, также генерируется явная проверка на отсутствие значения. Конструктор выдаст исключение NullPointerException, если какой-либо из параметров, предназначенных для полей, помеченных @NonNull, содержит значение null. Порядок следования параметров соответствует порядку полей в классе.


## @AllArgsConstructor
Сгенерирует конструктор с 1 параметром для каждого поля в вашем классе. Для @NonNull полей будут добавлена проверка в конструктор.


Просто Java:
```java
public class Author {
    private int id;
    private String name;
    private String surname;
    private final String birthPlace;
    
    // @NoArgsConstructor
    public Author() { }
    
    // @AllArgsConstructor
    public Author(int id, String name, String surname, String birthPlace) {
      this.id = id
      this.name = name
      this.surname = surname
      this.birthPlace = birthPlace
    }
    
    // @RequiredArgsConstructor
    public Author(String birthPlace) {
      this.birthPlace = birthPlace
    }
}
```


С Lombok:

```java
@NoArgsConstructor
@AllArgsConstructor
@RequiredArgsConstructor
public class Author {
	private int id;
	private String name;
	private String surname;
	private final String birthPlace;
}
```
