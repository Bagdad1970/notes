pytest позволяет использовать стандартное ключевое слово `assert` для проверки ожиданий и значений в тестах.

Пример:
```python
def f():
    return 3

def test_function():
    assert f() == 4
    
def test_passes():
    assert 2 + 2 == 4

def test_fails():
    assert 2 + 2 == 5
```

Через запятую можно указать AssertMessage:
`assert f() == 4, "Result of f is not equal 4"`

### Приближенное сравнение
При сравнении значений с плавающей запятой (или массивов чисел с плавающей запятой) часто возникают небольшие ошибки округления. Вместо использования `assert abs(a - b) < tol` или `numpy.isclose()` можно использовать `pytest.approx()`:

`approx(_expected_, _rel=None_, _abs=None_, _nan_ok=False_)`. Предположим, что два числа (или две упорядоченные последовательности чисел) равны друг другу в пределах некоторого допуска.

По умолчанию approx считает равными значения в пределах относительного допуска от 1e до 6 (т.е. одна часть на миллион) от ожидаемого значения. Такая обработка привела бы к неожиданным результатам, если бы ожидаемое значение было равно 0,0, потому что ничто, кроме 0,0, само по себе не является относительно близким к 0,0. Чтобы не вызывать удивления в этом случае, approx также считает равными значения в пределах абсолютного допуска от 1e до 12 от ожидаемого значения. Бесконечность и NaN являются частными случаями. Бесконечность считается равной только самой себе, независимо от относительного допуска. По умолчанию значение NaN не считается равным чему-либо, но вы можете сделать его равным самому себе, установив для аргумента nan_ok значение True. (Это предназначено для облегчения сравнения массивов, в которых значение NaN означает “нет данных”).
