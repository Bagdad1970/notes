Фикстуры в pytest представляют собой функции, которые можно использовать при автоматизации тестирования для решения следующих задач:
- обеспечения пред и пост условий
- вынос типовых действий в отдельные компоненты

Схема фикстуры:
```python
import os

@pytest.fixture(scope='function', autouse=False)
def create_temp_file():   
    with open("test.txt", "w") as f:  
        f.write("Hello, World!")  
  
    yield "test.txt"
  
    os.remove("test.txt")
```
`scope` - область действия фикстуры. Может быть `['session', 'package', 'module', 'class', 'function']`
`autouse` - если True, то фикстура запускается для всех тестов в области видимости. Если значение есть False (по умолчанию), то для активации фикстуры требуется явная ссылка.

В фикстурах вместо return может использоваться yield. С помощью этих фикстур можно выполнить некоторый код и передать значение обратно в запрашивающую фикстуру или тест.

Использование `yield` позволяет после теста выполнить завершающий код (все, что размещено после `yield`)

pytest запускает фикстуры в линейном порядке, пока фикстура не вернет результат или не завершит работу

После завершения теста pytest вернется к списку фикстур, но в обратном порядке, и будет выполнять код внутри каждой фикстуры, начиная с оператора yield.

conftest.py - специальный файл, в котором объявляются общие для всех тестов фикстуры.
