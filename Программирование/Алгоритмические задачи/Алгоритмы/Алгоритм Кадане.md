
**Цель**: Найти макс сумму подпоследовательности в массиве.

**Описание:** Пусть дан целочисленный массив.
Для любого элемента есть выбор:
1. Если текущая сумма положительная, то суммировать с новым элементом
2. Если текущая сумма отрицательная, то начинать сумму с нового элемента

```python
def max_sub_array(nums: list[int]) -> int:  
    if len(nums) == 1:  
        return nums[0]  
  
    max_sum = nums[0]  
    current_sum = nums[0]  
  
    for num in nums[1:]:  
        current_sum = max(current_sum + num, num)  
        max_sum = max(max_sum, current_sum)  
  
    return max_sum
```
