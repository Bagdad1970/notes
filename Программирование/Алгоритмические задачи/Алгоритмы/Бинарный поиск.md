Цель: поиск элемента в структуре данных

Пусть дан отсортированный массив. Заполним индекс среднего элемента. Если элемент среднего индекса меньше цели, то зададим левую границу подмассива как `middle_index + 1`, если же элемент больше цели, то правой границей будет `middle_index - 1`.

```python
def binary_search(nums: list[int], target: int) -> int:  
    if not nums:  
        return -1  
  
    left, right = 0, len(nums) - 1  
    while left <= right:  
        middle_index = left + (right - left) // 2  # для избеждания переполнения переменной
  
        if nums[middle_index] == target:  
            return middle_index  
        elif nums[middle_index] > target:  
            right = middle_index - 1  
        elif nums[middle_index] < target:  
            left = middle_index + 1  
  
    return -1
```
