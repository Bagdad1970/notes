```python
s = input()  
  
digit_dict = {}  
for char in s:  
    if char not in digit_dict:  
        digit_dict[char] = 1  
    else:  
        digit_dict[char] += 1  
  
sorted_keys = sorted(digit_dict.keys())  
result = ""  
if sorted_keys[0] == '0':  
    result += sorted_keys[1]  
    result += sorted_keys[0] * digit_dict.get('0')  
    result += sorted_keys[1] * (digit_dict.get(sorted_keys[1]) -  1)  
    for digit in sorted_keys[2:]:  
        result += digit * digit_dict.get(digit)  
else:  
    for digit in sorted_keys:  
        result += digit * digit_dict.get(digit)  
  
print(result)
```

Сложность:
- Временная - $O(n)$
- Пространственная - $O(1)$ т.к. хранится меньше или 9 записей
