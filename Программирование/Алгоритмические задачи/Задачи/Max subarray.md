### Условие
Дан целочисленный массив `nums`. Найдите непрерывный подмассив (содержащий как минимум одно число), который имеет наибольшую сумму, и верните эту сумму.

**Примечание:** Подмассив — это непрерывная часть массива.

**Пример 1:**
Ввод: nums = `[-2,1,-3,4,-1,2,1,-5,4]`
Вывод: 6

**Объяснение:** Подмассив `[4,-1,2,1]` имеет наибольшую сумму 6.

**Пример 2:**
Ввод: nums = `[1]`
Вывод: 1

**Объяснение:** Подмассив `[1]` имеет наибольшую сумму 1.

**Пример 3:**
Ввод: nums = `[5,4,-1,7,8]`
Вывод: 23

**Объяснение:** Подмассив `[5,4,-1,7,8]` имеет наибольшую сумму 23.

**Ограничения:**
- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`

### Решение
Через алгоритм Кадане.

```python
def max_sub_array(nums: list[int]) -> int:  
    if len(nums) == 1:  
        return nums[0]  
  
    max_sum = nums[0]  
    current_sum = nums[0]  
  
    for num in nums[1:]:  
        current_sum = max(current_sum + num, num)  
        max_sum = max(max_sum, current_sum)  
  
    return max_sum
```
