Исключение Java представляет собой объект, описывающий исключительное (ошибочное) состояние, которое произошло внутри фрагмента кода. Когда возникает исключение, JVM генерирует объект-исключение, который затем передается по стеку вызовов, пока не будет найден блок кода, способный его обработать.

### Иерархия исключений

![[Untitled Diagram.drawio.png]]

Только объекты класса Throwable и его наследники могут генерироваться JVM и использоваться в операторе throw и catch. Объект Throwable (и его потомки) содержит снимок стека выполнения своего потока на момент создания. Также может содержать строку сообщения об ошибке.

Error - представляет серьезные ошибки, которые **нельзя обработать во время выполнения** программы. Например: OutOfMemoryError, StackOverflowError.

Exception - представляет ошибки самой программы, которые **можно обработать во время выполнения**.
Исключения делятся на:
1. Проверяемые (checked). Объявляются в сигнатуре метода с помощью throws или обрабатываются внутри с помощью try-catch.
   Примеры: IOException, ClassNotFoundException.
2. Непроверяемые (unchecked). Являются наследниками класса RuntimeException. Не требуют явной обработки или объявления в сигнатуре метода. Обычно являются результатом ошибок в программе или непредвиденных условий.
   Примеры: NullPointerException, ArrayIndexOutOfBoundsException.

### Синтаксис исключений
Для обработки исключений используется следующий синтаксис:
```java
try {
	// исполняемый код, где могут быть ошибки
}
catch (тип_исключения1 объект_искл) {
	// обработка данного исключения
}
...  // дополнительные catch, если нужно
finally {
	// код, который должен быть выполнен в любом случае
}
```

Для генерации исключения в коде используется `throw`.
Пример:
```java
if (a >= 100) {
	throw new RuntimeException("The variable a must be less than 100")
}
```

Ключевое слово `throws` используется в сигнатуре метода для указания списка исключений, которые метод может генерировать. При вызове метода необходимо либо обработать эти исключения, либо передать исключение выше по стеку вызовов.
Пример:
```java
InputStream createFileInputStream(String filename) throws IOException {
	return new FileInputStream(filename);
}
```
