**Cloneable** - маркерный интерфейс, указывающий методу Object.clone() возможность копирования экземпляров этого класса по полям. [Javadoc](https://docs.oracle.com/javase/8/docs/api/java/lang/Cloneable.html)

Вызов метода Object.clone() в экземпляре, который не реализует интерфейс Cloneable, генерирует исключение `CloneNotSupportedException`.

Метод `Object.clone()` создает и возвращает копию объекта.

#### Виды клонирования:
1. Shallow copy (поверхностное клонирование) - копирует только примитивные поля, а ссылочные продолжают указывать на тот же объект в памяти.
```java
@AllArgsConstructor
class Company implements Cloneable {
    String name;

    public Company clone() throws CloneNotSupportedException{`
        return (Company) super.clone();
    }
}
```

2. Deep copy (глубокое клонирование) - копирует и примитивные, и ссылочные поля. Для реализация необходимо у вложенных классов также реализовать клонирование.

```java
@AllArgsConstructor
class Company implements Cloneable {
    String name;

    public Company clone() throws CloneNotSupportedException{`
        return (Company) super.clone();
    }
}

@AllArgsConstructor
class Person implements Cloneable {
    String name;
    Company company;
 
    public Person clone() throws CloneNotSupportedException{
        Person person = (Person) super.clone();
        person.company = (Company) company.clone();
        return person;
    }
}
```
