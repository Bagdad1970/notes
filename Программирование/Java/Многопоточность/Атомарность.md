Для выполнения операции атомарно в Java используются классы из пакета `java.util.concurrent.atomic`, такие как `AtomicInteger`, `AtomicBoolean`, `AtomicReference`, `AtomicLong` идругие. Эти классы используют машинные инструкции, которые гарантируют атомарность без использования блокировок и являются потокобезопасными.


Рассмотрим пример со счетчиком:
```java
class Counter {
    private volatile long counter = 0;
    
    long getCounter() { return counter; }
    void increment() { counter++;  }
}

public class Program {
    public static void main(String[] args) throws InterruptedException{
        int numThreads = 10; // количество потоков
        int incrementsPerThread = 1000; // количество итреаций в каждом потоке
        
        Counter counter = new Counter();
        
        Thread[] threads = new Thread[numThreads];
        for (int i = 0; i < numThreads; i++) {
            threads[i] = new Thread(() -> { 
                for (int j = 0; j < incrementsPerThread; j++) {
                    counter.increment();
                }
            });
            threads[i].start();
        }
        // задержка, чтобы потоки успели поработать
        Thread.sleep(1000);
        
        for (int i = 0; i < numThreads; i++){
            threads[i].join();
        }
 
        System.out.println("Counter: " + counter.getCounter());
    }
}
```

Сама по себе операция `counter++` вместо одного шага состоит из трех шагов:
1. Чтение текущее значение `counter` (из основной памяти т.к. `volatile`);
2. Изменение значения;
3. Записывается новое значение `counter` (в основную память т.к. `volatile`).

Предположим ситуацию, что два потока (А и Б) вызывают `increment()` одновременно:
1. Поток А читает `counter` (значение 0).
2. Поток Б читает `counter` (значение 0).
3. Поток А изменяет свое значение на 1 и записывает 1 в `counter`.
4. Поток Б изменяет "свое" значение (которое все еще 0) на 1 и записывает 1 в `counter`.

Таким образом, мы можем получить некорректный результат, а `volatile` не позволяет избежать состояния гонки во время составной операции.

Для того, чтобы починить программу необходимо внести изменения в класс Counter:
```java
class Counter{
    private AtomicLong counter = new AtomicLong(0);
 
    long getCounter() { return counter.get(); }
    void increment() { counter.getAndIncrement(); }
}
```
