Input/Output в Java выполняется через потоки данных.
Поток данных (stream) - это абстракция, которая либо производит, либо потребляет информацию. Поток связан с физическим устройством посред­ством системы ввода-вывода Java.
Поток является блокирующим т.е. поток ждет пока операция ввода-вывода не будет завершена.

Потоки в Java делятся на:
- Байтовые. Базовые классы: InputStream (представляет поток ввода), OutputStream (представляет поток вывода)
- Символьные. Базовые классы: Reader (представляет поток ввода), Writer (представляет поток вывода)

**Замечание**: на низшем уровне взаимодействия с I/O все операции выполняются над байтами

## System
Класс, предоставляющий доступ к стандартным потокам I/O: in (чтение из консоли), out (вывод на консоль), err (вывод ошибок на консоль).
