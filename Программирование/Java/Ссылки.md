
Ссылки в Java делятся на:
1. Сильные (Strong)
2. Мягкие (Soft)
3. Слабые (Weak)
4. Фантомные (Phantom)

### Сильная ссылка
Является базовым типом ссылок. Когда создается объект и присваивается переменной, то создается сильная ссылка на объект. Объект будет оставаться в памяти, пока на него есть хотя бы одна такая ссылка.
```java
Integer prime = 1;
```

### Мягкая ссылка
Позволяет JVM удалить объект из памяти при ее нехватке.
Полезна для кэширования данных или оптимизации производительности.
```java
SoftReference<String> soft = new SoftReference<String>("Some text"); 
```

### Слабая ссылка
Объекты, на которые ссылаются только слабые ссылки, быстро удаляются сборшиком мусора, даже если памяти достаточно.
Полезна для кэширования временных данных.
```java
WeakReference<String> weak = new WeakReference<String>("Some text");
```

### Фантомная ссылка
Используется для отслеживания объектов перед их удалением из памяти, что позволяет выполнять определенные действия перед его окончательным удалением.
```java
ReferenceQueue<String> queue = new ReferenceQueue<>();
PhantomReference<String> phantomRef = new PhantomReference<>("Some text", queue);
```
