# Аннотации
Аннотации в Java представляют специальную форму метаданных, которую можно добавлять в исходный код. Они предоставляют дополнительную информацию о программе, которая может использоваться компилятором, инструментами сборки, фреймворками или во время выполнения.
Аннотации позволяет отделить конфигурацию и метаданные от основной бизнес-логики.

Сами по себе аннотации лишь маркируют элементы кода (классы, методы и  т.д.), а уже обработчик аннотаций в свою очередь ищет эти маркеры и выполняет на их основе определенную логику.

Некоторые встроенные аннотации:
- **@Override**: указывает компилятору, что текущий метод переопределяет метод из суперкласса.
- **@Deprecated**. Помечает элемент кода как устаревший
- **@FunctionalInterface**. Указывает, что интерфейс предназначен для использования в качестве функционального интерфейса.

Все интерфейсы аннотаций неявно расширяют интерфейс `java.lang.annotation.Annotation`, который является обычным интерфейсом.

При создании аннотации часто используются мета-аннотации:
- **@Retention**. Определяет политику хранения.
- **@Target**. Указывает, к каким элементам кода можно применять аннотацию (класс, метод, поле и т.д.). С помощью enum `ElementType` можно указать к какому элементу кода аннотация применима.
- **@Documented**. Указывает, что аннотация должна быть включена в генерируемую Javadoc-документацию.
- **@Inherited**. Указывает, что аннотация, примененная к классу, будет наследоваться его подклассами.
- **@Repeatable**. Позволяет применять одну и ту же аннотацию к одному элементу несколько раз.
### Retention
Может иметь одно из 3 значений enum `RetentionPolicy`:
- **SOURCE**: аннотация существует только в исходном коде и отбрасывается компилятором.
- **CLASS** (по умолчанию): аннотация сохраняется в файле `.class` (в байт-коде), но недоступна во время выполнения.
- **RUNTIME**: аннотация сохраняется в файле `.class`, но в отличие от предыдущего варианта аннотация доступна во время выполнения через рефлексию.

### Пример создания аннотации
```java
@interface MyAnnotation {
	String message();
	int val() default -1;  // можно указывать значения по умолчанию
}
```

# Рефлексия
Рефлексия — это механизм исследования и изменения данных о программе во время её выполнения. Рефлексия позволяет исследовать информацию о полях, методах и конструкторах классов.

Доступна в пакете java.lang.reflect.
